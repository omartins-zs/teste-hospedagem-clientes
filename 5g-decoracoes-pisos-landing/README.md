# 5G Decorações - Landing Page

Landing page profissional para negócio de venda e instalação de pisos laminados e click.

## 🚀 Como Editar o Número do WhatsApp

Para alterar o número do WhatsApp em todo o site, edite o arquivo **`config.js`**:

```javascript
const CONFIG = {
    whatsappNumber: '11999999999', // ⬅️ Coloque seu número aqui (apenas números, com DDD)
    whatsappMessage: 'Olá,%20gostaria%20de%20um%20orçamento%20para%20piso'
};
```

**Exemplos:**
- São Paulo: `11999999999`
- Rio de Janeiro: `21999999999`
- Belo Horizonte: `31999999999`

O número será atualizado automaticamente em todos os botões e links do WhatsApp no site.

## 📁 Estrutura de Arquivos

- `index.html` - Página principal
- `script.js` - Validação de formulário e funcionalidades
- `config.js` - Configuração do WhatsApp
- `pisos.jpg` - Imagem de fundo do hero
- `shopping.jpg` - Imagem adicional (se necessário)

## 🎨 Personalização

### Cores
As cores principais estão definidas no HTML usando classes Tailwind:
- Marrom/Amber: `amber-700`, `amber-800`
- Cinza: `gray-50`, `gray-800`
- Verde WhatsApp: `#25d366`

### Textos
Todos os textos podem ser editados diretamente no arquivo `index.html`.
